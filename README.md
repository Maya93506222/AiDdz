# 经典斗地主 AI 推理能力测试

一个在浏览器里运行的三人斗地主单机牌桌，用来测试外部 AI 的出牌推理能力。

一个人在同一台电脑上依次操控甲、乙、丙三家，三家都明牌显示。轮到某一家出牌时，程序自动生成一份**只含这一家视角**的提示词：自己的手牌，加上所有人都看得到的公开信息。你把提示词复制给外部 AI，看它怎么出，再在牌桌上手动照做或另行操作。

程序本身不调用任何 AI，不联网，也不会自动采纳 AI 的建议。

## 快速开始

1. 下载整个目录。
2. 用 Chrome 或 Edge 双击打开 `ddz.html`。

不用安装，不用联网，也不用启动服务器。

⚠ 一定要保留完整目录。只拷走 `ddz.html` 是打不开的，运行需要下面 6 个文件放在同一个文件夹里：

`ddz.html`、`styles.css`、`cards.js`、`game.js`、`prompt.js`、`ui.js`

缺了任何一个，页面顶部会显示「请保留完整目录及全部 CSS、JS 文件」，所有按钮都不能点。

## 怎么用

### 一局的流程

1. **发牌**：打开页面就自动洗牌、发牌，每家 17 张，留 3 张底牌，并随机选一家先叫分。
2. **叫分**：轮到的那家在自己手牌区下方点「不叫」「1 分」「2 分」「3 分」。三家各叫一次，后叫的必须比前面高，叫到 3 分立即结束。
   - 最高分的一家当地主，拿走 3 张底牌，然后先出牌；
   - 三家都不叫，就点「重新发牌」。
3. **出牌**：轮到的那家点选手牌，被选中的牌会上移，再点「出牌」；不想压就点「不要」，选错了点「取消选择」。
   - 出牌顺序固定为甲 → 乙 → 丙 → 甲；
   - 自由出牌（新一轮的第一手）时不能选「不要」。
4. **结束**：任何一家出完手牌，牌局立即结束，右侧「本局结算」显示胜负、倍数和三家得分。

当前轮到谁，手牌区会用红框加「当前玩家」字样标出。只有当前玩家的按钮能点，另外两家的按钮会变灰。出错时（比如牌型不对、压不过），牌桌上方的提示行会写明原因，牌局不会被改动。

### 测试 AI

1. 叫完分进入出牌阶段后，页面底部的提示词区会自动生成当前玩家的提示词。
2. 点「复制提示词」，粘贴给外部 AI。
3. 提示词会要求 AI 按四项作答：建议操作、具体牌面（带花色）、牌型、简要理由。
4. 回到牌桌，按 AI 的建议出牌，或者自己决定。下一家的提示词会随之更新。

**提示词里有什么**：

- 当前玩家自己的完整手牌；
- 叫分过程、地主、底牌；
- 三家的身份和剩余张数，另外两家写「手牌不公开」；
- 按轮汇总的出牌和「不要」记录。

**提示词里没有什么**：另外两家没打出的牌、发牌时的初始手牌。牌桌上虽然三家都明牌，那只是方便你操作，不会进入提示词。

**规则怎么告诉 AI**：提示词开头一句引用线上规则页 `https://transmiao.cn/ddz-rule.html`，不复述规则条文。如果你用的 AI 打不开网址，请把本目录里的 `ddz-rule.html` 内容一起发给它。

## 存档、导入和导出

页面底部那一行按钮：

| 按钮 | 作用 | 存在哪里 | 能不能发给 AI |
|---|---|---|---|
| 保存提示词 | 把当前提示词存成 `斗地主提示词_日期_时间.md`，内容和「复制提示词」复制出来的完全一样 | 浏览器的下载目录 | ✅ 可以，不含别家手牌 |
| 保存牌局 | 把当前局面存进右边的下拉框，最多存 20 局 | 浏览器本地存储 | — |
| 回放牌局 | 把下拉框里选中的那局恢复到牌桌上 | — | — |
| 删除牌局 | 删掉下拉框里选中的那局 | — | — |
| 导出牌局 | 把当前局面存成 `斗地主牌局_日期_时间.json` | 浏览器的下载目录 | ❌ 不行，含三家全部手牌 |
| 导入牌局 | 选一个导出的 `.json` 文件，恢复那一局 | — | — |

几点说明：

- **「保存牌局」不是真正的文件**，它存在浏览器自己的数据里。换个浏览器就看不到了，复制目录也带不走；清理浏览器的「Cookie 和网站数据」会把它一起删掉，在无痕窗口里存的局，窗口一关也就没了。想长期保留或带到别的电脑，用「导出牌局」。
- **导入前会按规则检查**：程序会从发牌开始，把文件里的记录用规则重演一遍。哪一步不合规则，或者重演出来的局面和文件对不上，就拒绝导入，并写明是第几条记录、哪一家的哪一项不对，牌桌保持原样。手工改出来的残局文件，只要能通过这项检查，同样可以导入。
- **只认 `.json` 存档**。提示词文件还原不出完整牌局，因为里面没有另外两家的牌，所以不能导入。
- **示例残局**：`经典斗地主残局.json` 是一局打到后半段的残局，导入后轮到丙（地主）出牌，可以直接拿来测 AI。

## 规则

完整规则见 `ddz-rule.html`，用浏览器打开即可。本项目采用的是一套统一口径，和一些平台不完全一样，主要几点：

- 一轮叫分，三家各叫一次，叫 3 分立即结束；全不叫就重新发牌。
- 牌型共 14 种：单张、对子、三张、三带一、三带二、顺子、连对、飞机（不带、带单、带对）、四带二（带两张单牌、带两个对子）、炸弹、火箭。
- 顺子、连对、飞机只能用 3 到 A，不能带 2 和王；四带二不算炸弹。
- 每打出一个炸弹或火箭，倍数翻一倍；春天、反春也各翻一倍。
- 计分：设叫分为 B、最终倍数为 M，地主赢时地主 +2BM、两个农民各 −BM；农民赢时反过来。三家得分加起来始终为 0。

## 开发与测试

- 运行游戏不需要任何依赖。
- 跑测试需要 Node.js 18.11 或更高版本（推荐 20 LTS 以上），不用安装任何包：

```bash
node --test tests.js
```

当前共 91 条测试，覆盖牌型识别与比较、叫分、出牌、计分、提示词内容、导入检查，以及若干安全方面的静态检查（不使用 `innerHTML`、不联网、不读剪贴板等）。

测试只加载 `cards.js`、`game.js`、`prompt.js`，不加载界面脚本 `ui.js`。界面上的操作靠在浏览器里手动验收。

改动代码时，以代码和 `tests.js` 为准，并同步更新 `ddz_spec.md`。

## 已知限制

- 刷新或关闭页面不会提醒，没保存的牌局会丢失。
- 不能撤销已经出的牌、叫的分。
- 「保存牌局」存满 20 局之后，新存档的编号会重复（显示问题，不影响回放）。
- 线上规则页和本地 `ddz-rule.html` 可能有出入，以你实际发给 AI 的那份为准。
- 没有专门适配手机，建议在电脑上用较宽的窗口打开（页面最小宽度 640px，再窄就要左右滚动）。

## 隐私

- 程序不联网，不向外发送任何数据。只有你自己复制、发送的提示词会离开这台电脑。
- 不读取剪贴板。
- 只有你点「导入牌局」并亲手选中文件时，才会读取那个文件。
